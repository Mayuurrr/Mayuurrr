Full-stack engineer shipping production features end-to-end — serverless AWS infrastructure on the backend, React and Angular on the front. Two years in, I've moved from writing individual components to owning system design conversations, API contracts, and the code review process around them.

I care about the unglamorous parts most people skip: query indexes, error-handling middleware, encryption at the field level, tests around the code paths that actually break in production. The interesting engineering is rarely in the feature itself — it's in what happens when 20,000 people hit it at once.

Before any of that, I studied Computer Science formally — data structures, operating systems, database internals — and I still reach for that foundation more often than any framework documentation.
